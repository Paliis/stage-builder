# Quick start

Stage Builder helps you lay out a stage in meters, check it in 3D, and prepare a printable briefing.

## Four steps

### 1. Field

At the top, set **width × length** in meters or pick a **preset**.

The plan shows a grid for placing targets.

### 2. Targets

1. Pick a target type in the **left panel**.  
2. **Click the plan** — each click adds one target.  
3. To stop placing: press **Esc** or click the same type again.

Move: select → drag. Delete: select → **Delete** or the × button near the map.

### 3. Check in 3D

Switch to the **3D** tab. Rotate the view — confirm visibility from the shooter’s perspective and behind shields.

### 4. Output

- **Briefing** tab — name, procedure, ammo, etc.  
- **Download PDF** — table + snapshot (open 3D first for an accurate image).  
- **Save stage** — file on disk to reopen or send to a colleague.
