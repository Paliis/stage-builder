# Текст діалогу «Інструкція» (скорочена версія)

> Після затвердження — перенести в `ukMessages.app` / `enMessages.app` у `messages.ts`.

## Заголовок і вступ

**Заголовок:** Stage Builder  

**Lead:** Конструктор вправ для практичної стрільби. За кілька хвилин можна накреслити майданчик, перевірити сцену в 3D і отримати PDF.

**Переваги (3–4 пункти, не 8):**

- план у метрах і перегляд у 3D;
- брифінг і PDF для друку;
- зберегти файл або поділитися посиланням.

## Крок за кроком (4 блоки)

### S1 — Майданчик

Розмір поля — угорі, метри або пресет.

### S2 — Мішені

Мішень зліва → клік по плану. Esc — вийти з режиму.

### S3 — 3D

Вкладка 3D — перевірте видимість мішеней.

### S4 — PDF і файл

Брифінг → PDF або «Зберегти вправу».

## Нижній блок

**Примітка (коротко):** Чернетка зберігається в цьому браузері. Для переносу на інший пристрій — збережіть файл.

**CTA:** Почати роботу  

**Посилання:** Детальна інструкція → `/uk/help` _(коли буде UH-40)_
