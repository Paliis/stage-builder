# Контекстні підказки — текст для UH-43

Показувати **один раз** (ключ у `localStorage`). Довжина ≤ 80 символів.

| triggerId | UK | EN |
|-----------|----|----|
| `placement-mode-first` | Оберіть тип зліва → клацайте по плану | Pick a type, then click the plan |
| `view-3d-first` | Обертайте сцену — перевірте видимість мішеней | Rotate the view to check visibility |
| `share-first` | Перегляд — для стрільців; редактор — обережно | View link for shooters; edit link is powerful |
| `range-signs-first` | Підпис у метрах; позиція вздовж поля | Label in meters; position along the field |
| `activation-first` | Два кліки: джерело → ціль | Two clicks: source, then target |
| `measure-first` | Два кліки на плані — довжина в метрах | Two clicks on the plan for length in meters |
