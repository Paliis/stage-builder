# Швидкий старт

Stage Builder допомагає накреслити вправу в метрах, перевірити її в 3D і зібрати брифінг для друку.

**Повне відео (1:45–2:00):** [перша вправа від поля до PDF](../videos/production/first-stage-full.md) — рекомендуємо почати з нього; короткі рілси — вирізки з того ж запису.

## Чотири кроки

### 1. Майданчик

У верхній панелі задайте **ширину і довжину** поля в метрах або оберіть **готовий розмір** зі списку (наприклад **20 × 30 м**).

На плані з’явиться сітка кроком **0,5 м** — по ній зручно ставити мішені. Масштаб — коліщатком; зсув плану — **пробіл** + перетягування мишою.

**Відео (35 с):** рілс `field-size` — сценарій зйомки: [videos/production/field-size.md](../videos/production/field-size.md) _(після зйомки тут буде посилання на YouTube/Telegram)_.

### 2. Мішені

1. У **лівій панелі** оберіть тип мішені.  
2. **Клацайте по плану** — кожен клік ставить одну мішень.  
3. Щоб закінчити розстановку — клавіша **Esc** або знову та сама кнопка типу.

Перемістити: клік по мішені → перетягнути. Видалити: виділити → **Delete** або кнопка з хрестиком біля карти.

### 3. Перевірка в 3D

Перемкніть вкладку **3D** угорі. Обертайте сцену мишкою — перевірте, чи мішені видно з позиції стрільця, чи не закриті щитами.

### 4. Результат

- Вкладка **Брифінг** — назва, процедура, боєприпаси тощо.  
- **Завантажити PDF** — таблиця + знімок (краще спочатку відкрити 3D).  
- **Зберегти вправу** — файл на комп’ютер, щоб відкрити пізніше або надіслати колезі.
