# Експорт .psc для PractiScore

## Для кого

**Організатор** або MD після формування матчу, заявок і програми вправ.

## Кроки (загально)

1. Кабінет організатора → оберіть **матч**.  
2. Переконайтесь, що **програма вправ** заповнена (посилання share).  
3. **Завантажити PSC** / **Експорт** — збережіть файл `.psc`.  
4. Імпортуйте в **PractiScore** за звичною процедурою MD.

## Якщо кнопки немає

Експорт може бути **вимкнений** на тестовому середовищі або ще не налаштований для вашого матчу — зверніться в підтримку Shooters Tools.
