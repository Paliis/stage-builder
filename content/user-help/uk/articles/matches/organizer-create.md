# Організатор: створити матч

**Повне відео (~2:00):** [matches-organizer-full](../../../videos/production/matches-organizer-full.md)

## Передумови

- **Акаунт** на сайті.  
- Роль **організатора** після модерації платформи (заявка в акаунті).

## Кроки

1. **Акаунт** → кабінет **організатора** → **Новий матч**.  
2. Заповніть: **назва**, **дати**, **місце**, **опис**, ліміти, дивізіони (за формою).  
3. **Опублікуйте** — матч з’явиться в публічному каталозі.  
4. Вправи: у **Stage Builder** зберіть сцену → **Поділитися** → посилання **перегляду** `/v/…` → у кабінеті додайте в **програму вправ** ([детально](./organizer-stages.md)).  
5. Приймайте **заявки**, формуйте **скводи** і **ростер** ([organizer-roster](./organizer-roster.md)).  
6. Експорт **`.psc`** для PractiScore — [export-psc](./export-psc.md).
