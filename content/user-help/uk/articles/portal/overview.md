# Shooters Tools — що тут є

Один сайт для підготовки до практичної стрільби: накреслити вправу, записатися на матч, порахувати hit factor, знайти правило на секторі.

## Модулі

| Модуль | Для кого | Що робить |
|--------|----------|-----------|
| **Stage Builder** | RO, організатор, тренер | План вправи в метрах, 3D, PDF, файл вправи |
| **Матчі** | стрілець, організатор | Каталог подій, заявки, кабінет організатора |
| **RO Helper** | RO | Пошук по правилах і процедурах |
| **Hit Factor** | стрілець | Калькулятор на лінії |
| **Акаунт** | усі | Профіль для заявок на матчі |

## Мова

Перемикач **UK** / **EN** у шапці — вибір зберігається.
