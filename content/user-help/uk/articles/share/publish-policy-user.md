# Публікація вправи: що важливо знати

Перед **Поділитися** ви погоджуєтесь з політикою публікації. Коротко:

## Що потрапляє в хмару

- Геометрія сцени (мішені, реквізит, розмір поля).  
- Текст **брифінгу** (назва, процедура тощо).

## Хто бачить

Усі, хто має **посилання**. Сторінки share **не призначені** для індексації пошуком.

## Що не варто публікувати

- ПІБ, телефони, адреси без згоди.  
- Внутрішні нотатки клубу, якщо це конфіденційно.

## Два рівні доступу

- **Перегляд** — для стрільців.  
- **Редактор** — лише для команди, якій довіряєте.
