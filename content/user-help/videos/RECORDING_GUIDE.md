# Як знімати відео Stage Builder

**Рекомендація:** спочатку один запис **1:45–2:00** — [production/first-stage-full.md](./production/first-stage-full.md).  
Короткі рілси 30–60 с — **нарізка** з нього в CapCut, не окремі дублі.

Загальні поради нижче. Покадровий сценарій — у `production/<slug>.md`.

---

## 1. Чим записувати (Windows)

| Інструмент | Плюси | Мінуси |
|------------|-------|--------|
| **OBS Studio** (безкоштовно) | Чітко, 60 fps, окрема сцена «тільки вікно браузера» | Треба 10 хв на налаштування |
| **Win + G** (Xbox Game Bar) | Вже в Windows, швидко | Інколи різкий fps, менше контролю |
| **ShareX** | Зручно для коротких кліпів | Для рілса краще OBS |
| **Телефон знімає монітор** | — | **Не рекомендуємо** — мерехтіння, розмиття |

**Рекомендація:** OBS, запис **вікна Chrome/Edge** (не всього екрана), **1920×1080**, **60 fps**.

---

## 2. Перед записом

1. **Чиста вправа** — кошик на карті; без зайвих мішеней (крім демо-сцени для конкретного рілса).
2. Мова **UK**, вікно **≥ 1280 px**, масштаб браузера **100%**.
3. Закрити діалог інструкції (incognito або вже натиснули «Почати»).
4. Вимкнути сповіщення Windows / Telegram.
5. **Репетиція 2 рази** без запису — по таймінгу з `production/*.md`.
6. Курсор **повільний**, пауза **0,3 с** після кожного кліка.

---

## 3. Кадр і формат

| Платформа | Співвідношення | Як зняти |
|-----------|----------------|----------|
| Instagram Reels / TikTok | **9:16** | OBS: canvas 1080×1920, crop браузера по центру **або** зняти 16:9 і обрізати в CapCut |
| YouTube Shorts | 9:16 | Те саме |
| Telegram | 1:1 або 9:16 | 1:1 — квадратний crop плану |
| Сайт / help | **16:9** | Повне вікно редактора |

**Порада:** знімайте **широко (16:9)** — потім у монтажі зробите 9:16. Так не обріжете панель інструментів.

**Зона в кадрі:** верхня панель (розмір поля) + план 2D по центру; бічну панель можна трохи звузити вікном, але **не ховайте** поля «ширина / довжина».

---

## 4. Звук

| Варіант | Коли |
|---------|------|
| **Без голосу + субтитри** | Найпростіше; SRT з `production/*.srt` |
| **Короткий VO** (1–2 речення) | Тиха кімната, мікрофон 15–20 см, −12 dB у монтажі |
| **Музика фоном** | −20…−24 dB, без слів у треку |

Для першого рілса (`field-size`) достатньо **субтитрів без голосу**.

---

## 5. Монтаж (мінімум)

1. **CapCut** (безкоштовно) або DaVinci Resolve.
2. Імпорт `.srt` → авто-субтитри (перевірити текст).
3. Обрізати паузи > 0,5 с.
4. Титри 0:00 і 0:30 — за `production/field-size.md`.
5. Експорт: **1080p**, H.264, 30 fps для соцмереж достатньо.

---

## 6. Типові помилки

- Занадто швидкий курсор — глядач не встигає.
- Запис **всього монітора** з панеллю задач і чатом.
- Staging-стрічка «тестове середовище» в кадрі — знімайте **production** або обріжте.
- Довгий ввід цифр «наживо» — краще **один** спосіб: або пресет, або ручний ввід (не обидва поспіхом).
- Субтитри перекривають поля вводу в момент кліка — опустити нижче або зменшити шрифт.

---

## 7. Після зйомки

1. `publishedUrl` → [manifest.json](./manifest.json).
2. Статус рілса → `published` у [PROGRESS.md](../PROGRESS.md).
3. Посилання в статтю / quick-start (блок «Відео»).

---

## 8. Перший рілс — мінімальний сетап OBS (5 хв)

1. Сцена → Джерело **Захоплення вікна** → Chrome з Stage Builder.
2. Налаштування → Вихід → **1920×1080**, 60 fps.
3. Кнопка **Почати запис** → виконати сценарій [production/field-size.md](./production/field-size.md).
4. Зупинити → файл у `Відео` → монтаж + SRT.
