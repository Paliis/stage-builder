## Приймання фінальної версії

1. За 5 секунд зрозумілий біль організатора.
2. До 20-ї секунди видно 2D → 3D → погляд стрільця.
3. Є зв’язна історія «вправа → бібліотека → матч → учасники → оплата → PractiScore».
4. Усі release-кадри реальні; після launch немає бейджа «Незабаром».
5. Субтитри читабельні у 9:16, CTA не обрізано.
6. Немає технічного жаргону та покрокових інструкцій.
