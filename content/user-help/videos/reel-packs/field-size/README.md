# Pack: field-size

Онбординг-рілс **«Розмір поля»** (~35 с): 6 кадрів у `pack.json` для збірки у проєкті «Відео агент».

**screenshots: pending** — PNG ще не зняті з реального UI. Нижче — як зробити кожен файл за ~2 хвилини.

## Як зняти скріни

Відкрийте `https://shooters-tools.com/uk/stage-builder` (або локальний `/{locale}/stage-builder`). Мова **UK**, масштаб браузера **100%**, закрийте «Інструкцію», очистіть вправу (кошик). Вікно ≥1280 px по ширині.

| Файл | Як отримати |
|------|-------------|
| `01_title.png` | Опційно: чорний/темний фон + текст «Розмір поля» у Figma/CapCut **або** будь-який чистий кадр редактора — Відео агент може зібрати титр без цього файлу, якщо позначить hold end-card. Для єдності pack: зніміть порожній редактор і додайте текст у монтажі. |
| `02_enter_20x30.png` | У шапці введіть ширину **20**, довжину **30**, Enter/blur. Скрін: видно поля метрів і план 20×30. |
| `03_preset_open.png` | Відкрийте меню **пресетів** біля розміру поля. Скрін з розкритим списком (або з уже обраним пресетом 20×30, якщо меню закривається одразу — тоді кадр «після вибору пресету» з підсвіченим контролом). |
| `04_grid_plan.png` | Закрийте меню. Зум так, щоб було видно **всю сітку** поля й лінійки. Без мішеней. |
| `05_zoom.png` | **Ctrl + коліщатко** (або **+** на пульті) — збільште план. Скрін крупнішої сітки. |
| `06_cta.png` | Окремий end-card: текст Stage Builder + `shooters-tools.com` (Figma / CapCut) **або** скрін головної / шапки з логотипом. |

Імена файлів мають **точно** збігатися з `pack.json` → `frames[].file`.

Після додавання всіх PNG змініть цей рядок на **screenshots: ready**.
