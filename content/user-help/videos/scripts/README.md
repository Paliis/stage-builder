# Сценарії рілсів

Головна серія — **коротка продуктова презентація**, а не покрокове навчання.

## Product-first (пріоритет)

1. `ecosystem-hero` — від вправи до готового матчу
2. `stage-builder-value` — ключові переваги редактора
3. `match-organizer-flow` — повний цикл організатора
4. `shooter-event-flow` — шлях учасника

Старі `field-size`, `place-target` та інші вузькі сценарії лишаються **P2 help/tutorial**.

Кожен файл — **таймінг + результат у кадрі + природний VO + субтитри UK**.
