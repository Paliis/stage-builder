## 1. Вступ — 0:00–0:13

**Текст диктора**

> Підготовка матчу завжди складається з багатьох частин: вправ, брифінгів, заявок, скводів, оплати та підготовки файлу для PractiScore.
>
> Портал Shooters Tools допомагає зібрати все це в одному місці та зручно керувати кожним етапом.

**Кадри**

- Головна Shooters Tools з активними подіями.
- Коротке наближення до Stage Builder.
- Швидкий монтаж: 3D-вправа → картка матчу → скводи → PractiScore.

**Субтитр:** `Від вправи до готового матчу`

## Монтажні правила

- Диктор говорить природно, без прискорення наприкінці речень.
- Між розділами залишати 0,2–0,4 секунди на візуальний перехід.
- Курсор і довге введення даних не показувати.
- Для багаточастинних сторінок використовувати плавне перетікання, а не швидку прокрутку.
- Субтитри — не більше двох коротких рядків.
- ПІБ, телефони, фото й технічні ідентифікатори розмити.
- API-токен Monobank не показувати.
- Для 9:16 зробити окремий монтаж із керованим pan широких таблиць.
- Практичний запас: VO може відрізнятися від плану на ±5 секунд після пробного озвучення.
