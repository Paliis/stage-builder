## Подача

- Темп енергійний: 3–6 с на вигоду.
- Не показувати заповнення полів і рух курсора довше секунди.
- Переходи через результат: 2D → 3D, PDF → бібліотека, бібліотека → програма матчу.
- Розділ «Матчі» показуємо як чинну частину єдиної екосистеми, без бейджа **«Незабаром»**.
- Для переходу «Мої вправи → програма матчу» використовуємо реальні кадри бібліотеки та наповненої програми, без мокапу.
