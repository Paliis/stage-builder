## Подача

- Темп енергійний: 3–6 с на вигоду.
- Не показувати заповнення полів і рух курсора довше секунди.
- Переходи через результат: 2D → 3D, PDF → бібліотека, бібліотека → програма матчу.
- До production-launch кадри розділу «Матчі» можуть мати невеликий бейдж **«Незабаром»**. Релізна версія — без бейджа.
- Кадр «Мої вправи → програма матчу» знімати після реалізації MA-C04, без мокапу.
