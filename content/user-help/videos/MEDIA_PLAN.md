**Оновлено:** 2026-08-09  
**Головна історія:** **від ідеї вправи до готового матчу — в одній екосистемі**. Stage Builder є ядром, а розділ «Матчі» продовжує роботу організатора: подія, програма зі збережених вправ, учасники, оплата та файл для PractiScore.

## 1. Продуктова лінійка

Це не покрокові інструкції. Кожен кадр показує **користь або результат**, а не окремий клік.

| Порядок | Ролик | ~час | Головний меседж | Стан |
|--------:|-------|------|-----------------|------|
| 1 | `ecosystem-hero` | 55–60 с | Вправа → подія → учасники → оплата → PractiScore | P0, перший pack |
| 2 | `stage-builder-value` | 35–40 с | Точний 2D-план, 3D з місця стрільця, PDF/QR, власна бібліотека | P0 |
| 3 | `match-organizer-flow` | 50–60 с | Створити матч і додати збережені вправи, прийняти заявки та оплату | P0, реліз «Матчів» |
| 4 | `shooter-event-flow` | 30–40 с | Знайти подію, переглянути програму, зареєструватися й оплатити | P1 |

### Довідкові мікрогайди (P2 help)

`field-size`, `place-target`, `view-3d-shooter`, `briefing-pdf`, `save-stage-file`, `shield-and-3d`, `measure-distance`, `mobile-place-delete`, `share-link`, `plan-tools-overview`, `activations-quick`, `open-shared-view`.

Вони лишаються для help-центру, але **не формують перше враження про продукт**.

### Інші модулі

RO Helper і Hit Factor можна показати коротко на фінальному end-card як частини Shooters Tools. Окремі ролики про них — після запуску головної лінійки Stage Builder + «Матчі».

## 3. Як передавати Відео агенту

### 3.1. Перед передачею (обов’язково)

У `reel-packs/<slug>/README.md` має бути **`screenshots: ready`**, і всі файли з `pack.json` → `frames[].file` лежать у тій папці.

Якщо `pending` — Відео агент може зібрати лише **чернетку без цього кадру**. Фінальний реліз не приймається, поки всі обов’язкові кадри не `ready`.

### 3.2. Що копіювати в чат Відео агента

```
Збери ролик з pack Stage Builder.
Шлях: content/user-help/videos/reel-packs/<SLUG>
Формати: 16:9, 9:16
Додай VO + субтитри + легку музику за pack.json.
Мова: українська. Не вигадуй кадри UI поза PNG з папки.
Темп: динамічний, 2–4 секунди на кадр; акцент на результаті для організатора, не на курсорі.
Поверни: файли відео + короткий список відхилень від pack.json (якщо були).
```

Підставте `<SLUG>` (`field-size`, `place-target`, …).  
Якщо Відео агент живе в іншому репо — скопіюйте **всю папку** `reel-packs/<slug>/` туди або дайте абсолютний шлях до Stage Builder.

### 3.3. Що має повернути Відео агент

- Відео **16:9** (сайт / YouTube)
- Відео **9:16** (Shorts / Reels / Telegram)
- (бажано) текст VO, який реально озвучили, якщо відрізняється від `pack.json`

## 4. Як перевіряти (рев’ю перед публікацією)

Переглянути обидва формати. Достатньо **одного проходу** на ролик.

| # | Питання | Ок? |
|---|---------|-----|
| 1 | За перші 5 секунд зрозумілий біль організатора? | |
| 2 | До 20-ї секунди видно головну перевагу Stage Builder: 2D → 3D → готовий матеріал? | |
| 3 | Є цілісний шлях «вправа → матч», а не набір випадкових екранів? | |
| 4 | Тривалість близька до сценарію (±10%), без кадрів довше 4–5 с без причини? | |
| 5 | Субтитри читабельні на 9:16 і не перекривають ключовий UI? | |
| 6 | VO людський, без технічного жаргону й переліку кнопок? | |
| 7 | Кінцівка містить «Shooters Tools — від вправи до матчу» та URL? | |
| 8 | Немає вигаданого UI; release-функції зняті з реального staging/production? | |

**Провал** → правки в pack (нові скріни / текст у `pack.json`) → знову Відео агент.  
**Ок** → публікуєте → у `manifest.json` для цього slug: `publishedUrl` + статус на кшталт `published`.

Швидка перевірка продукту в кадрі: відкрити [shooters-tools.com/uk/stage-builder](https://shooters-tools.com/uk/stage-builder) і звірити кнопки/підписи з роликом.

## 5. Стан продукту в кадрі

- «Матчі», реєстрацію та онлайн-оплату показуємо як чинні можливості, без бейджа **«незабаром»**.
- Для історії **«Мої вправи» → програма матчу** використовуємо реальну бібліотеку й реальну наповнену програму події.
- Експорт називаємо **«готовий файл матчу для PractiScore»**, не «двостороння синхронізація».
