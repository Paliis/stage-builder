# Рілс — `field-size` (вирізка)

> **Знімати окремо не обов’язково.** Уривок **0:10–0:22** з майстер-відео [first-stage-full.md](./first-stage-full.md) (~2 хв, повна вправа).

**Статус:** extract-after-master · **Тривалість:** 35 с (після нарізки) · **Формат:** 9:16 (1080×1920) або 1:1 — на ваш канал; нижче орієнтир **16:9 desktop** для screen record.

**Короткий опис для соцмереж:** Як задати розмір майданчика в метрах у Stage Builder — за 10 секунд.

**Після публікації:** вставити `publishedUrl` у [../manifest.json](../manifest.json).

---

**Як знімати взагалі (OBS, формат, звук):** [RECORDING_GUIDE.md](../RECORDING_GUIDE.md).

## Перед зйомкою (чекліст)

- [ ] Відкрити **http://localhost:5174/stage-builder** (або production), мова **UK**.
- [ ] **Очистити вправу** (червоний кошик на карті) — порожнє поле за замовчуванням (30×40) або після очищення.
- [ ] Закрити діалог «Інструкція», якщо з’явився (або incognito + `localStorage` без онбордингу).
- [ ] Вікно браузера **≥ 1280 px** ширини, масштаб сторінки **100%**.
- [ ] Прибрати зайві вкладки; вимкнути сповіщення ОС.
- [ ] Запис екрана: **60 fps**, курсор видимий, **кліків мало** — рухи плавні.
- [ ] (Опційно) Тиха музика −18 dB під субтитри; **без** VO, якщо лише субтитри.

**Не показувати в кадрі:** staging-стрічку (якщо тестове середовище — знімайте з production або обріжте).

## Що показуємо в UI (точні підписи UK)

| Елемент | Де | Текст у інтерфейсі |
|---------|-----|-------------------|
| Ширина | Верхня панель | «Площадка (шир × дов)» → поле ширини, **м** |
| Довжина | Поруч | поле довжини, **м** |
| Пресети | Випадаючий список | «Пресети…» → наприклад **20 × 30 м** |
| Сітка | План 2D | Крок **0,5 м**, лінійки по краю |
| Масштаб | План | Коліщатко миші |

**Пресет для демо в кадрі:** **20 × 30 м** (є в списку; типовий майданчик).

**Альтернатива ручного вводу:** ширина **20**, довжина **30** — як у сценарії нижче.

## Покадровий сценарій (зйомка)

| № | Час | Дія на екрані (репетиція) | Субтитр на відео (UK) | EN (якщо потрібно) |
|---|-----|---------------------------|------------------------|---------------------|
| 1 | 0:00–0:02 | **Титр** (Canva/CapCut): білий текст на темному | **Розмір поля за 10 секунд** | Set field size in 10 seconds |
| 2 | 0:02–0:09 | Курсор у поле **ширини** → ввести `20` → Tab або клік у **довжину** → `30` → Enter / клік поза полем | **Введіть ширину і довжину в метрах** | Enter width and length in metres |
| 3 | 0:09–0:16 | Клік **«Пресети…»** → обрати **20 × 30 м** (план оновиться) | **Або оберіть готовий пресет** | Or pick a preset |
| 4 | 0:16–0:24 | Повільний **зум коліщатком** на план — видно **сітку** і **лінійки** по краю | **Сітка 0,5 м — зручно ставити мішені** | 0.5 m grid for placing targets |
| 5 | 0:24–0:30 | Легкий **зсув** (пробіл + drag або середня кнопка) — показати, що план рухається | **Масштаб — коліщатком. Зсув — пробіл + миша** | Zoom: scroll. Pan: Space + drag |
| 6 | 0:30–0:35 | **Титр-кінець:** лого / текст URL | **shooters-tools.com/stage-builder** | shooters-tools.com/stage-builder |

**Примітка:** блоки 2 і 3 можна **скоротити** — залишити лише пресет (0:02–0:12) + сітка (0:12–0:28), якщо рілс треба у **25 с**.

## Текст за кадром (VO) — опційно

Один варіант голосу (~12 с, накласти на 0:02–0:14):

> «Спочатку задайте розмір майданчика: метри вгорі або пресет зі списку. Сітка допоможе розставити мішені рівно.»

Якщо **без голосу** — достатньо субтитрів з таблиці.

## Постпродакшн

- Обрізати паузи > 0,5 с між кліками.
- Субтитри: **Roboto** або системний sans, **білий** з чорною обводкою, низ **20%** кадру.
- Перший і останній кадр — **1 с** статичний титр.
- Експорт: H.264, 1080p; для Reels — 1080×1920, < 60 MB.
