# План детальних роликів за розділами

Головний master-ролик знайомить із цілою екосистемою. Серія нижче пояснює окремі сценарії глибше, але кожен ролик усе одно починається з результату, а не з переліку кнопок.

## 1. Stage Builder: від задуму до готової вправи

**Тривалість:** 2:40  
**Результат:** користувач розуміє повний цикл 2D → 3D → брифінг → PDF → збереження.

| Час | Зміст |
| ---- | ----- |
| 0:00–0:10 | Готова вправа в 2D, 3D і PDF. Хук: «Спочатку подивімося, що буде готово наприкінці». |
| 0:10–0:30 | Розмір майданчика, покриття, метрична сітка та масштаб. |
| 0:30–1:05 | Мішені, штрафні мішені, декорації, стартові позиції та штрафні лінії. Показувати групами, без пояснення кожної кнопки. |
| 1:05–1:25 | Переміщення, поворот, дублювання, видалення та вимірювання дистанції. |
| 1:25–1:50 | Перехід у 3D, загальний огляд і погляд зі стартової позиції. |
| 1:50–2:15 | Автоматичні дані брифінгу, ручне уточнення тексту й формування PDF. |
| 2:15–2:32 | Назва вправи, «Зберегти» та «Мої вправи». |
| 2:32–2:40 | Підсумок: «Плануйте, перевіряйте й готуйте матеріали в одному редакторі». |

**Головний текст:** «Не потрібно окремо малювати схему, збирати брифінг і переносити дані в документ. Вправа проходить увесь шлях в одному редакторі».

## 2. Створення й налаштування матчу

**Тривалість:** 2:40  
**Результат:** організатор бачить, як створити повноцінну подію та підготувати її до публікації.

| Час | Зміст |
| ---- | ----- |
| 0:00–0:10 | Готова публічна картка матчу, програма та заявки. |
| 0:10–0:35 | Назва, дата, час, місце, обкладинка, тип події, дисципліна та рівень. |
| 0:35–1:00 | Основні й прематч-скводи: кількість груп, місткість і загальний ліміт. |
| 1:00–1:20 | Стартові внески: стандартний і пільгові варіанти. |
| 1:20–1:40 | Опис події, статус публікації та видимість списку учасників. |
| 1:40–2:05 | Програма матчу: вправи Stage Builder або один PDF-брифінг програми. |
| 2:05–2:22 | Коли програма стане доступною стрільцям. |
| 2:22–2:32 | Збереження й перевірка публічної картки. |
| 2:32–2:40 | Підсумок: «Одна картка — усі дані, потрібні учаснику». |

**Не перевантажувати:** технічними деталями форматів дат, внутрішніми статусами БД та налаштуванням API.

## 10. Hit Factor: аналіз результату

**Тривалість:** 1:30  
**Результат:** стрілець бачить, як оцінити вплив часу та кожного промаху.

План: готовий приклад → введення часу й очок → внесок кожного пострілу → порівняння сценаріїв → короткий висновок для тренування.

Не називати інструмент офіційним калькулятором результатів матчу; це аналітичний помічник.

---

## 11. RO Helper: швидка довідка судді

**Тривалість:** 1:30  
**Результат:** RO швидко знаходить потрібну процедуру без довгого пошуку в правилах.

План: типова ситуація на вправі → пошук → коротка відповідь → посилання на правило → суміжні процедури та штрафи.

Підкреслити: RO Helper допомагає знайти норму, але не замінює чинну редакцію офіційних правил і рішення суддівської команди.

## Єдині правила серії

- Перші 5–8 секунд — готовий результат і причина дивитися далі.
- Один ролик відповідає на одне практичне питання.
- VO — природна українська, 125–145 слів за хвилину.
- Кліки й введення даних прискорювати; важливий стан тримати 3–5 секунд.
- Субтитри — максимум два короткі рядки.
- Основний master — 16:9; для 9:16 робити окремий crop, а не автоматично обрізати краї.
- Учасники, телефони, фото, токени та технічні ID не мають потрапляти у фінальний ролик.
- Кожен ролик завершується наступною логічною дією, а не однаковим рекламним CTA.

## Порядок виробництва

1. Зібрати pack для чотирьох P0-роликів.
2. Перевірити тексти диктора на реальному темпі.
3. Зробити один тестовий монтаж 16:9.
4. Після затвердження стилю зібрати решту P0/P1 у тому самому оформленні.
5. Окремо адаптувати 9:16: крупніші callout, менше таблиць одночасно, керований pan.
