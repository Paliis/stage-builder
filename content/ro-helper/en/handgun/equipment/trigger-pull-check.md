## What this is

Trigger pull weight below the minimum set for the Production or Production Optics divisions.

## RO algorithm

1. **Inspect:** measure with the official weights. The barrel must point vertically up.
2. **Assess:** run the first test. If the firearm released (a quiet drop) — the shooter is entitled to 2 more attempts.
3. **Action:** minimum first-shot pull weight — 2.27 kg (5 lbs) per Appendix D4.
4. **Document:** if the firearm fails all 3 attempts — the RM moves the shooter to the Open division.

## Key nuances (Jan 2026)

* **Firearm state:** the test runs in first-shot ready state (DA, or hammer cocked for striker-fired — per Appendix D4).
* **Attempts:** the shooter may not adjust the firearm between attempts during the check.

## Common RO mistakes

* Running only one measurement attempt (the rules require up to 3 attempts on a negative result).
