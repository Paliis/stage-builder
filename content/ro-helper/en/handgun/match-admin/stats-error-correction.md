## What this is

Separating a **stats technical error** (time / zone entry) under **9.10** from an **RO decision protest** under **11.3** with the fee and deadlines (2026 logic).

## RO algorithm (legal protocol)

1. **Identify:** clarify the type of issue — an obvious arithmetic / logical data error (impossible time, duplicated string) — **9.10**; disagreement with the **RO**'s call on a hit / procedure — **protest** under **11.3**.
2. **Document:** the Stats Officer cross-checks the paper duplicate, ESS log, shooter signature; for a **protest** — application, fee, target preservation per **section 11**.
3. **Escalate:** an entry error — fixed via the **Stats Officer** and **RM** without a full arbitration if the primary rules permit; a dispute with an RO call — only via **11.3** and the **arbitration committee**.
4. **Record decision:** update the **official scoreboard**; record the correction time; for a **protest** — append the committee's decision to the match history.

## Key nuances (Jan 2026)

* A **technical error** normally needs no monetary fee; an **RO decision protest** is under **11.3**.
* Verification deadlines (e.g. the window after publication) — follow the **MD** regulations and **9.10**.

## Common RO mistakes

* Refusing to fix an obvious data glitch because "the string is closed", contrary to **9.10**.
