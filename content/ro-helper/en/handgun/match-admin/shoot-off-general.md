## What this is

Failure to follow the **shoot-off** format, in which two shooters run identical lanes in parallel under **1.2.2**.

## RO algorithm

1. **Verification:** confirm both lanes are identical (distances, angles, steel calibration) per MD/RM.
2. **Assessment:** make sure both shooters are in the correct **ready state** and understood the shoot-off WSB.
3. **Requirements:** issue **one** start signal only after both are ready; an early start is not allowed.
4. **Document:** record the moment the **stop plate** falls; in case of a simultaneous or unclear result — re-run per **1.2.2** and the match procedure.

## Key nuances (Jan 2026)

* **Stop plate:** must unambiguously decide the run (typically the dedicated stop plate); calibration per the MD briefing.
* **REF:** a technical malfunction on one lane — reshoot for **both** competitors per match procedure and **1.2.2**.

## Local (FPSU)

MD regulations on the **shoot-off** and the number of re-runs; disputed falls are decided by the RM.

## Common RO mistakes

* A start before both shooters have settled into the WSB-defined start position.
