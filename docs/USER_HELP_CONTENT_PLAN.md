### 3.6. FAQ Stage Builder (повні відповіді UK)

| ID | Питання | Відповідь |
|----|---------|-----------|
| F-SB01 | Де вправа після закриття вкладки? | Зміни **автоматично зберігаються в цьому браузері** (чернетка). Після **«Зберегти»** в акаунт — у **«Моїх вправах»** на будь-якому пристрої (автозбереження ~30 с). Файл `*.stage.json` — окремий експорт. |
| F-SB02 | Акаунт, файл, чернетка, посилання — різниця? | **«Мої вправи»** — ваша хмара після входу. **Файл** — ви пересилаєте самі. **Чернетка** — лише в цьому браузері. **Посилання** (`/v/`, `/e/`) — опублікована копія для перегляду або спільного редагування. |
| F-SB03 | Чому мішень пунктиром? | Увімкнено **кути безпеки** в брифінгу й є **старт**. Це **підказка**, не рішення РО. |
| F-SB04 | PDF не як на екрані? | Спочатку відкрийте **3D** і дочекайтесь сцени, потім експортуйте PDF. |
| F-SB05 | Редагувати з `/v/`? | **Ні** — `/v/` лише перегляд. Потрібен `/e/` або файл у редакторі. |
| F-SB06 | Один тап на телефоні? | Після одного дотику режим розстановки **вимикається** — щоб не ставити зайве. |
| F-SB07 | Видалити без клавіатури? | Виділіть об’єкт → **хрестик** біля карти або **довгий тап** (~0,5 с). |
| F-SB08 | Смуга «Оновити»? | Вийшла **нова версія сайту** — натисніть, інакше PDF може зламатися. |
| F-SB09 | Без інтернету? | Після першого відкриття багато працює **офлайн**. **Поділитися** потребує мережі. |
| F-SB10 | Мінімум пострілів у лічильнику? | Це **орієнтир** для брифінгу, не офіційний мінімум змагання. |
| F-SB11 | NS-мішені? | Окремі кнопки **NS** у палітрі — не зараховуються в ураження. |
| F-SB12 | Активації? | Режим **Активація** → два кліки по об’єктах. Детально — стаття `activations`. |
| F-SB13 | Таблички дистанцій? | Кнопка **«Дистанції»** біля карти. Детально — `range-distance-signs`. |
| F-SB14 | Очистити все? | **Червоний кошик** на карті — вся вправа; файл на диску не чіпає. |

→ Перенести в `uk/faq.md` секція «Stage Builder».
